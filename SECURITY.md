# Security policy

## Supported versions

Security fixes are applied to the latest published fxrs release. Older
pre-release versions may require upgrading.

## Reporting a vulnerability

Please use the repository's private
[security advisory form](https://github.com/Leeeon233/fx-rs/security/advisories/new).
Do not open a public issue for an unpatched vulnerability, and never include
real credentials, OAuth tokens, or private source code in a report.

Include the affected version, platform, reproduction steps, impact, and any
suggested mitigation. Maintainers will coordinate disclosure after a fix is
available.
